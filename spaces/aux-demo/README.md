# AUX synthetic UX demonstration

This Docker Space is a self-contained demonstration for the local `aux_backup`
folder. It previews the configure, live trace, and report contracts without claiming
to run a browser or real users.

The production application requires separately deployed control-plane, persona,
Journey, and Eyeson services. The fixture displayed here is explicitly labeled
`offline_contract_demo` and all findings are labeled simulated, inferred, or proposed.

Health endpoint: `GET /healthz`.
